# 소리 탐험대

초등학생을 위한 소리 탐구 웹앱. 마이크로 들어온 소리의 **크기(dB)** 를 재고, **파형과 주파수**를 눈으로 비교합니다.

## 무엇을 할 수 있나요

- **소리 온도계** — 0~120dB 막대에 `속삭임 30`, `보통 대화 60`, `청소기 70`, `지하철 95` 같은 생활 소음 눈금이 함께 표시되어, 지금 낸 소리가 무엇과 비슷한지 바로 읽힙니다. 5단계 색과 표정으로도 알려 줍니다.
- **파형 화면** — 오실로스코프처럼 실시간 물결을 그립니다. 보이는 시간(10 / 25 / 50ms)이 고정이라 **높은 소리는 물결이 촘촘하고 낮은 소리는 넓게** 보입니다.
- **멈춰서 관찰** — 정지하면 파형이 그대로 멈춥니다. `가장 큰 순간 보기`로 측정 중 가장 컸던 순간의 파형을 다시 꺼내 볼 수 있습니다.
- **주파수 탭** — 스펙트럼 막대로 소리에 어떤 높낮이가 섞여 있는지 봅니다.
- **저장해서 비교** — 소리를 카드로 저장하고 이름을 붙여 나란히 놓고 비교합니다. 처음부터 `낮은 도(131Hz)` / `높은 도(523Hz)` 예시 카드가 들어 있습니다.
- 진폭(%), 주파수(Hz), 가장 가까운 계이름(도레미)을 함께 보여 줍니다.

PC / 태블릿 / 휴대폰 반응형이고, 다크 모드를 지원합니다.

## 수업 전 준비

기기마다 마이크 감도가 달라서 절대값은 어림값입니다. **조용한 교실에서 30~40dB이 나오도록** 왼쪽 아래 `마이크 보정` 슬라이더를 한 번 맞춰 두면 훨씬 그럴듯한 값이 나옵니다.

## 실행

의존성도 빌드도 없는 정적 사이트입니다.

```bash
# 그냥 파일을 브라우저로 열어도 됩니다
start index.html
```

마이크는 보안상 `https://` 또는 `localhost`, `file://` 에서만 동작합니다.

## 배포 (Vercel)

1. 이 저장소를 GitHub에 올립니다.
2. [vercel.com/new](https://vercel.com/new) 에서 저장소를 가져옵니다.
3. Framework Preset은 **Other**, Build Command와 Output Directory는 **비워 둡니다**.
4. Deploy를 누르면 끝입니다. 이후 `main`에 push할 때마다 자동 배포됩니다.

## 기술

바닐라 HTML/CSS/JS 한 파일. Web Audio API(`AnalyserNode`)로 파형·스펙트럼을 얻고, RMS로 dB를 계산하며, 자기상관(autocorrelation)으로 기본 주파수를 찾습니다. 그림은 모두 Canvas 2D입니다.
